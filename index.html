Engineering approach

How I build

These patterns come up again and again in my projects.

Deterministic where it matters

LLMs explain and extract; rules decide. In Scheme Finder, eligibility is checked by Python rules, not the model, so answers can't be hallucinated.

Cost-aware by design

Cheap filters run before expensive models. JobHunt narrows about 2,000 postings to about 40 with zero LLM calls, so a daily run costs a few rupees.

Fail safe, not fail loud

Provider fallback chains, validate-then-compile pipelines, and local data fallbacks mean a single outage doesn't break the product.

Secure by default

Untrusted code runs in network-less Docker containers with CPU and memory caps. APIs get rate limits, body caps, JWT auth and hardened headers.

Measured, not guessed

Offline test suites with no network or keys, plus retrieval evals (routing, top-1, top-3), so I know when a change makes things worse.

Automated end to end

GitHub Actions for tests, nightly re-ingestion and scheduled agents, plus an AI pipeline that creates and posts My Carat's Instagram content. The work keeps running without me.
